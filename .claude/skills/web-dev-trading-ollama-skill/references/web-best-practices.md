# Web Dev Best Practices

## Lightweight Stack
- HTML5 semantic elements
- CSS custom properties (vars)
- JS modules/ES6+
- No build step for prototypes

## Performance
- Lazy load charts/images
- Debounce inputs
- Virtual scrolling for large tables
