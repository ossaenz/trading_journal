⚙️ Initial Setup Required

Before you start: This app requires OAuth configuration.

1. Google Drive API Setup

  1. Go to Google Cloud Console
  2. Create new project: "QuantumWheel Trading"
  3. Enable: Google Drive API v3
  4. Create OAuth 2.0 Client ID (Application type: Web app)
  5. Add authorized redirect URI: https://yourusername.github.io/trading_journal/
  6. Copy Client ID below

2. Charles Schwab API Setup

  1. Visit developer.schwab.com
  2. Register your app in Schwab Developer Portal
  3. Get Client ID and Client Secret
  4. Configure redirect: https://yourusername.github.io/trading_journal/callback

Your credentials are stored locally in this browser only. Never shared externally.
